# MiSans 界面字体回退设计

> 文档版本：1.0
> 更新日期：2026-08-28
> 适用范围：Linux 端全局字体回退栈（`lib/core/config/theme/app_theme.dart`）、CJK 字形变体
> 反馈致谢：感谢 GitHub 用户 `EvernightFedora` 在 issue #22 中提出界面优先使用 MiSans 字体的建议（简体、繁体、日文界面均适用）。

## 概述

应用界面在 Linux 上优先使用系统已安装的 MiSans 字体渲染中文文本。应用不内置
任何字体文件（MiSans 官方全家桶约 217MB，内置会使下载体积翻倍以上），仅在
字体回退栈中声明家族名：系统装有 MiSans 的用户自动生效，未安装的用户由
fontconfig 匹配不到该家族而自然落到后续 Noto/文泉驿字库，行为与引入前一致，
下载体积零增加。

## 字体覆盖实测

以下结论均来自对官方字体文件 cmap 字符表的逐字符实测，不是文档推断：

| 文字 | MiSans 覆盖 | 说明 |
|------|------------|------|
| 简体汉字 | 全覆盖 | 家族名 `MiSans`（静态字重包）/ `MiSans VF`（可变字体），均实测自 name 表 |
| 日文假名与汉字 | 全覆盖 | 含平/片假名、促音及 JIS 专属汉字（峠/辻/働），整体渲染不会混排 |
| 繁体汉字 | 码位全覆盖 | 門/轉/龍/發/麥/體等均可显示，笔形为中式/简体习惯而非台/港标准字形 |
| 韩文谚文 | 无 | 한글 等谚文字符全部缺失 |
| 阿拉伯文 | 无 | 由回退栈中的 Noto Sans Arabic 兜底 |
| 西里尔文 | 覆盖 | 俄语等语言可命中 MiSans |

## 各语言回退栈决策

- **简体（含所有非 CJK 语言的默认栈）**：`MiSans` / `MiSans VF` 前插，
  Noto/思源/文泉驿继续兜底缺字；
- **日文**：前插 MiSans。假名与汉字为中式笔形而非 JIS 惯例，对字形纯正度
  敏感的用户可移除系统 MiSans 自动回落 Noto Sans CJK JP；
- **繁中**：前插 MiSans（issue #22 讨论后的「方案 A」决定）。繁体码位全
  覆盖不会混排；笔形同上，敏感用户同样以卸载字体方式回落地区字库；
- **韩文**：不前插 MiSans。其 cmap 无任何谚文字符，前插对韩文文本无效果，
  谚文由 Noto Sans CJK KR 兜底；
- 阿拉伯语、俄语等其余语言无需改动：MiSans 覆盖的字符自动生效，不覆盖的
  字符由既有专用字体（Noto Sans Arabic 等）逐字符接管。

Flutter 的字体回退逐字符进行：回退栈命中失败最终由 fontconfig 在系统字体
中兜底，不会出现豆腐块；最坏情况是单个字符换用后续字体渲染，笔形略异。

## 范围排除

- 字体文件不随安装包发布，不新增字体子包；
- 不提供应用内字体选择设置项：曾有一份「界面字体偏好」实现（设置页分段
  按钮 + 持久化枚举 + 多语言翻译键）被评审否决——无人提出该需求，禁止在
  无用户诉求时为字体回退新增设置项、持久化字段或翻译键；
- monospace 等组件显式声明的专用字体不属于本策略范围。
