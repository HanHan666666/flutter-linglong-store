## 四、踩坑记录（给下一个执行者）

1. **Hive 同名 box 的 lazy 设置必须一致**：`openBox('cache')` 与 `openLazyBox('cache')` 混用会抛 `HiveError`。测试里自己开 box 的地方（`app_search_index_provider_test`、`app_repository_impl_test`）已统一为 LazyBox。
2. **mockito 的 `verify` 会消费调用记录**：连续两次 verify 同一方法，第二次只统计新调用。断言"总请求数"要在 mock 应答内自行记录（参考 ranking_provider_test 的 `sentRequests`）。
3. **`@freezed` 模型加字段**（如 RankingState）要跑 `dart run build_runner build --delete-conflicting-outputs`。
4. **Riverpod codegen provider 的 build() 里不能 await**：搜索索引的水合改为"build 返回 AsyncLoading + 异步方法回填 state"的模式。
5. **ll-cli 输出日志是规范**（docs/15），不要为了性能砍 stdout 逐行日志；stderr 的 64KB 有界缓冲不影响日志（日志照写，只是 CliOutput.stderr 文本封顶）。
6. 项目硬性约定：禁止 `PopupMenuButton`、禁止硬编码物理方向布局（RTL 门禁会拦）、每个功能点一个 commit。
