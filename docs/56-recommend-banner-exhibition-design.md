# 推荐页 Banner：浅色展台与深色画廊

## 背景与确认范围

首页原有 Banner 使用品牌渐变、模糊图标与玻璃信息停靠卡。
本次按用户确认的「精品应用展台」方向替换视觉：浅色主题使用珍珠灰展台，
深色主题使用石墨灰画廊；保持同一套构图，通过材质与光照体现主题差异。

仅修改推荐页 Banner 的表现层。继续消费 `BannerInfo`，保留原来的详情/外链
入口、30 秒自动轮播、手动切换、隐藏页暂停，以及页面缓存和推荐列表行为。
不新增服务端字段、推荐标签、评分、接口或 CLI 调用。

## 视觉与布局

- 阅读起始侧：32px 应用标题（最多两行）、14px 简介（最多两行）、查看详情按钮。
  标题有完整内容 Tooltip，描述缺失继续使用既有本地化占位文案。
- 阅读结束侧：真实应用图标、带细边缘高光的托板、两片弧形曲面与椭圆展台。
  造型全部由 Flutter 绘制，图标保持原始方向。
- 默认高度仍为 236px，圆角为 16px；随系统字号增大额外预留纵向空间，
  不通过关闭字体缩放解决溢出。
- Banner 宽度小于 600px 时，标题为 26px，展品简化为 72px 图标托板；
  保留标题、描述和详情操作，两侧继续为轮播按钮预留空间。
- 常规宽度下起始侧留白 88px、结束侧 72px；顶部 22px、底部 34px，
  为轮播控件和指示器留出独立区域。
- 上一项/下一项沿用 48px 点击区，主题化中性色描边；指示器采用深浅适配的
  短线，选中宽度 20px、未选中宽度 6px，高 4px，点击区为 32×24px。

## 主题与品牌取色

| 部位 | 浅色展台 | 深色画廊 |
| --- | --- | --- |
| 文字侧底色 | `#F4F5F7` 珍珠灰 | `#191D24` 石墨灰 |
| 展品侧底色 | 中性灰混入 7% 品牌色 | 中性灰混入 8% 品牌色 |
| 标题/主操作 | `#252B32` | `#F2F1ED` |
| 描述 | `#58616C` | `#B8BEC8` |
| 托板 | 浅色细腻切面、柔和阴影 | 深色切面、局部聚光与轮廓高光 |

继续复用 `RecommendBannerPaletteResolver` 的图标取色与缓存。
品牌色只影响局部反光及轻微背景色，不改变标题和描述的稳定前景色。
颜色测试覆盖红、绿、蓝、黄、紫、黑、白图标，两种主题的标题/描述相对
背景两端均满足至少 4.5:1 对比度。

主题或条目变化时立即使用当前主题的兜底调色板。异步取色使用请求序号，
过期结果不得覆盖新主题/新条目；图标缺失、失败时复用 `AppIcon` 占位。

## 实现与性能边界

- `recommend_page.dart`：保留轮播状态与路由，负责自适应高度、控件和指示器。
- `widgets/recommend_banner.dart`：文案、操作和展品组合；纯 props 输入，
  不订阅全局 Provider。
- `widgets/recommend_banner_background.dart`：统一管理取色生命周期，向内容下发
  同一份调色板。
- `widgets/recommend_banner_palette_resolver.dart`：复用已有取色逻辑并生成主题材质。

移除原有 `BackdropFilter`、`ImageFiltered`、重复的放大模糊品牌图与假预览窗。
曲面采用少量 Path 和渐变；柔光、接触阴影采用压缩的径向渐变。
托板只有局部 BoxShadow。展品使用 RepaintBoundary 隔离，CustomPainter 仅在
品牌色、主题或方向改变时请求重绘（尺寸变化由框架处理）。没有持续动画、
逐帧计算、额外依赖或在 build 中执行取色 IO，轮播使用既有切换动效。

## 无障碍与方向

- 详情、导航、指示器分别复用 `A11yButton` / `A11yIconButton`。
- 文案使用现有 l10n，按钮支持 Tab 聚焦和 Enter 激活。
- 装饰展品排除语义，避免占位字母与标题重复播报。
- 使用方向感知布局；RTL 下文案、展品和装饰镜像，应用图标自身不翻转。
- 方向箭头复用 Material 图标的 `matchTextDirection`，不叠加第二次镜像。

## 验证与试用

自动验证覆盖主题切换、窄宽度/长文案/1.5 倍字号、RTL 排列、键盘激活、
取色对比度和既有推荐页回归，并执行全库静态分析与方向布局门禁。
通过实际 Flutter 渲染核对两种主题的构图；这不替代 Linux 真机性能测量。

用户运行 `flutter run -d linux`，在设置中切换浅色/深色后返回首页，检查真实
推荐图标、窗口尺寸变化、按钮悬浮和手动轮播。真机帧耗时与内存指标尚未测量。
